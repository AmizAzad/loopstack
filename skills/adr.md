# /adr
Only for decisions costly to reverse or likely to be questioned. Never for trivial choices.
Write `docs/adr/NNNN-<slug>.md` (reuse the repo's ADR location/numbering if one exists) from `.loopstack/templates/adr.md`: context, problem, constraints, options, trade-offs, decision, consequences, revisit when. ≤1 page. Status `proposed` until the user accepts.
