# /document
- Audience first (user, operator, developer); write only what they need.
- Update docs the change touches: README, API spec, config, runbooks, ADRs, changelog.
- Examples over prose; commands that actually run; link instead of duplicating.
- Comments explain why, not what.
- Run documented commands/examples, or mark them untested.
